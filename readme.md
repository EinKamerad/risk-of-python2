# Risk of Python 2

Модульный 3D Roguelike от третьего лица на базе движка **Ursina Engine** (Python) по мотивам *Risk of Rain 2* с поддержкой кооператива по локальной сети (LAN) и коду комнаты.

## Особенности
* **3 класса выживших** с уникальными 3D-моделями и 4 способностями (`ЛКМ`, `ПКМ`, `Shift`, `R`):
  * **Commando** — скорострельный стрелок с тактическим перекатом и пробивным выстрелом.
  * **Artificer** — архимаг с плазменными AoE-сферами, реактивным взлётом и орбитальным ударом.
  * **Huntress** — мобильный снайпер с самонаводящимися стрелами, рикошетящей глефой и дождём стрел.
* **Кооператив по LAN и коду комнаты** — синхронизация генерации мира, врагов, босса, сундуков и игроков без внешних серверов (TCP + UDP Broadcast).
* **7 артефактов с механикой стаков** — *Soldier's Syringe*, *Paul's Goat Hoof*, *Tougher Times*, *Ukulele*, *Gasoline*, *Lens-Maker's Glasses*, *Hopoo Feather*.
* **4 биома и ИИ-Режиссёр (Combat Director)** — *Distant Roost*, *Scorched Acres*, *Abyssal Depths*, *Siren's Call* с динамическим ростом сложности со временем и битвой с боссом *Stone Titan* у древнего телепорта.
