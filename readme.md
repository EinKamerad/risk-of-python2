# Risk of Python 2

Модульный 3D Roguelike от третьего лица на базе движка **Ursina Engine** (Python) по мотивам *Risk of Rain 2* с поддержкой кооператива по локальной сети (LAN) и коду комнаты.

## Особенности
* **3 класса выживших** с уникальными 3D-моделями и 4 способностями (`ЛКМ`, `ПКМ`, `Shift`, `R`):
  * **Commando** — скорострельный стрелок с тактическим перекатом и пробивным выстрелом.
  * **Artificer** — архимаг с плазменными AoE-сферами, реактивным взлётом и орбитальным ударом.
  * **Huntress** — мобильный снайпер с самонаводящимися стрелами, рикошетящей глефой и дождём стрел.
* **Кооператив по LAN и коду комнаты** — синхронизация генерации мира, врагов, босса, сундуков и игроков без внешних серверов (TCP + UDP Broadcast).
* **7 артефактов с механикой стаков** — *Soldier's Syringe*, *Paul's Goat Hoof*, *Tougher Times*, *Ukulele*, *Gasoline*, *Lens-Maker's Glasses*, *Hopoo Feather*.
* **4 биома и ИИ-Режиссёр (Combat Director)** — *Distant Roost*, *Scorched Acres*, *Abyssal Depths*, *Siren's Call* с динамическим ростом сложности со временем и битвой с боссом *Stone Titan* у древнего телепорта.

## Установка и запуск

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
   cd rir2

2. Создайте и активируйте виртуальное окружение (рекомендуется Python 3.10+):

```bash
python3 -m venv .venv
source .venv/bin/activate  # Linux / macOS
# .venv\Scripts\activate   # Windows

3. Установите зависимости:

```bash
pip install -r requirements.txt

4. Запустите игру:

```bash
python3 main.py

### Управление

    * **W, A, S, D** — Передвижение

    * **Space** — Прыжок (двойной прыжок с Hopoo Feather)

    * **ЛКМ (M1) / ПКМ (M2)** — Основная и вторичная атака

    * **Shift** — Тактический навык перемещения

    * **R** — Ультимативная способность

    * **E** — Взаимодействие (открыть сундук, активировать алтарь или телепорт)

    * **Tab** — Детальная статистика персонажа и собранных предметов

    * **Esc** — Освободить / захватить курсор мыши

### Структура проекта

    * **main.py **— Точка входа, инициализация окна Ursina и обработка ввода

    * **config.py** — Баланс классов, база предметов, палитры биомов и сохранение прогресса

    * **models.py** — Процедурная генерация 3D-моделей выживших, монстров, предметов и космоса

    * **entities.py** — Логика игрока, сетевых союзников, снарядов, спецэффектов и ИИ врагов

    * **world.py** — Генерация этапов, физические коллизии, сундуки, алтари и телепорт

    * **ui.py** — Главное меню с 3D-диорамой, боевой интерфейс (HUD) и игровой цикл

    * **network.py** — Сетевой модуль (кодирование IP в код комнаты, автопоиск в LAN и синхронизация)
