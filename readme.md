# Risk of Python 2

Модульный 3D Roguelike от третьего лица на базе движка **Ursina Engine** (Python) по мотивам *Risk of Rain 2* с поддержкой кооператива по локальной сети (LAN) и коду комнаты.

## Особенности
* **14 классов выживших** с уникальными 3D-моделями и 4 способностями (`ЛКМ`, `ПКМ`, `Shift`, `R`):
  * **Commando, Artificer, Huntress, Enforcer** — классические герои.
  * **V1 (ULTRAKILL)** — FPS-режим с переключением 5 видов оружия, 3 руками (парирование, взрыв, крюк) и измерителем стиля.
  * **Sol Badguy (Guilty Gear), Gwen (LoL), Scout (DRG), Medic (TF2)** и другие кроссоверные персонажи с уникальными механиками (Убер-заряды, Dummy Link, переманивание боссов).
* **Кооператив по LAN и коду комнаты** — синхронизация генерации мира, врагов, босса, сундуков и игроков без внешних серверов (TCP + UDP Broadcast).
* **Богатый арсенал** — десятки обычных, необычных, легендарных предметов, а также артефакты Пустоты и Лунные предметы со штрафами.
* **4 биома + 2 секретных уровня** — случайная генерация с ИИ-Режиссёром (Combat Director). Торговля на Базаре Между Временем и финальная битва с Митриксом на Луне в Небесном Колизее.

## Установка и запуск (Для Astra Linux / Debian)

Из-за строгой политики безопасности и ограничений прав доступа на учебных компьютерах, системная установка модулей может быть заблокирована. Выполните эти шаги в терминале, чтобы установить игру локально для вашего пользователя:

1. Клонируйте репозиторий и перейдите в папку проекта:
   git clone <https://github.com/EinKamerad/risk-of-python2>
   cd rir2


2. Скачайте скрипт установщика `pip` прямо через терминал (с помощью `wget`):
wget [https://bootstrap.pypa.io/get-pip.py](https://bootstrap.pypa.io/get-pip.py)


3. Установите `pip` локально, игнорируя системные ограничения (флаг `break-system-packages` нужен в новых версиях Debian/Astra для обхода блокировки PEP 668):
python3 get-pip.py --user --break-system-packages


4. **Важно:** При локальной установке в Linux исполняемые файлы попадают в скрытую папку `~/.local/bin`, которой по умолчанию может не быть в путях системы (`PATH`). Добавьте её одной командой:
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc


5. Теперь установите движок Ursina и остальные зависимости проекта с теми же флагами обхода:
python3 -m pip install --user --break-system-packages -r requirements.txt



6. Запустите игру:
python3 main.py



### Управление

* **W, A, S, D** — Передвижение
* **Space** — Прыжок (двойной прыжок с Hopoo Feather)
* **ЛКМ (M1) / ПКМ (M2)** — Основная и вторичная атака
* **Shift** — Тактический навык перемещения
* **R** — Ультимативная способность
* **E** — Взаимодействие (открыть сундук, активировать алтарь или телепорт)
* **F / G / V** — Альтернативные действия (например, парирование у V1 или смена цели Телепорта)
* **Tab** — Детальная статистика персонажа, инвентарь и статус сети (удерживать)
* **Esc** — Меню паузы / Освободить курсор мыши

### Структура проекта

* **main.py** — Точка входа, инициализация окна Ursina и обработка ввода.
* **config.py** — Баланс классов, база предметов, палитры биомов и сохранение прогресса.
* **models/** — Процедурная генерация 3D-моделей выживших, монстров, боссов, предметов и космоса.
* **entities/** — Логика игрока (включая уникальный FPS-код для V1), союзников, снарядов, спецэффектов, ИИ врагов и боссов.
* **world/** — Генерация этапов, физические коллизии, сундуки, алтари, телепорт и спец-уровни (Базар, Луна).
* **ui/** — Главное меню с интерактивной 3D-диорамой, Журнал (Logbook), сетевое лобби и боевой HUD.
* **network.py** — Сетевой модуль (TCP + UDP, кодирование IP в код комнаты, автопоиск в LAN).
